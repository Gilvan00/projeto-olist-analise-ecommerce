# Justificativa do Problema e da Escolha dos Dados — Projeto Olist

## 1. Contextualização do problema

O comércio eletrônico gera grandes volumes de dados relacionados a pedidos, clientes, produtos, pagamentos e entregas. A análise dessas informações permite compreender o comportamento das vendas, identificar padrões de consumo e avaliar o desempenho das operações logísticas.

Neste projeto, o problema analisado consiste em compreender o desempenho comercial e logístico de uma operação de comércio eletrônico, identificando padrões e oportunidades de melhoria por meio da análise de dados.

## 2. Justificativa da escolha do problema

A escolha desse tema está relacionada à importância da análise de dados para empresas que atuam no comércio eletrônico.

Informações sobre faturamento, categorias de produtos, distribuição geográfica dos pedidos e prazos de entrega podem contribuir para decisões mais eficientes nas áreas comercial e logística.

A análise permite transformar dados operacionais em informações relevantes para identificar tendências, avaliar resultados e apoiar o planejamento estratégico.

## 3. Justificativa da escolha da base de dados

Para desenvolver o projeto, foi escolhido o **Brazilian E-Commerce Public Dataset by Olist**, disponibilizado publicamente na plataforma Kaggle.

A base reúne informações reais e anonimizadas de operações de comércio eletrônico realizadas no Brasil, abrangendo o período de 2016 a 2018.

O conjunto de dados é composto por diferentes tabelas relacionadas a pedidos, clientes, produtos, vendedores, pagamentos, avaliações e informações geográficas.

A escolha foi motivada por:

- Volume significativo de registros para análise.
- Diversidade de informações comerciais e logísticas.
- Relacionamento entre diferentes tabelas.
- Possibilidade de investigar indicadores de vendas e entregas.
- Aplicabilidade dos dados a situações reais do comércio eletrônico.

## 4. Adequação dos dados ao projeto

A estrutura da base permite desenvolver análises sobre:

- Volume e evolução mensal dos pedidos.
- Receita por categoria de produto.
- Distribuição geográfica dos pedidos.
- Situação dos pedidos.
- Tempo médio de entrega.
- Pontualidade das entregas.
- Relação entre preço dos produtos e valores de frete.

Essas informações são adequadas aos objetivos do projeto e permitem explorar diferentes dimensões do negócio.

## 5. Objetivo geral

Analisar os dados públicos do comércio eletrônico da Olist utilizando PySpark e ferramentas de visualização, buscando identificar padrões de vendas, características da distribuição dos pedidos e indicadores de desempenho logístico.

## 6. Ferramentas utilizadas

- **Google Colab:** ambiente de desenvolvimento.
- **Python:** linguagem de programação.
- **PySpark:** processamento e análise dos dados.
- **Looker Studio:** construção do dashboard interativo.
- **Google Drive:** armazenamento dos arquivos utilizados durante o desenvolvimento.
